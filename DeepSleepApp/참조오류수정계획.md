### 1. 중복 타입 정의 오류
- `ChatMessage`, `MessageSender`, `ChatMessageType`, `QuickAction`, `ChatMetadata`가 `SharedModels.swift`와 `UserDefaults+Extensions.swift`에서 중복 정의
- `RecommendationUserContext`가 `SharedCore.swift`와 `ComprehensiveRecommendationEngine.swift`에서 중복 정의
- `SoundRecommendationContext`가 `Models.swift`와 `SharedModels.swift`에서 중복 정의

### 2. 찾을 수 없는 타입/함수
- `LongTermMemoryManager` (ComprehensiveRecommendationEngine.swift)
- `AIModelSettingsView` (SettingsViewController.swift)
- API 호출 형식 불일치 (`.analyzeEmotion`, `.recommendSound` 등)

### 3. 기타 문제
- `ConsoleLogger.swift`에서 error 함수 호출 오류
- TimeContext의 currentTime 프로퍼티 없음
